# Getting Started

Welcome to **LowFrame**.

This section explains how to join the server, protect your username, travel, create unlimited homes, use shops, claim rewards, and understand important gameplay differences.

## Start Here

1. Join LowFrame using the address for your platform.

2. Register your username when prompted.

3. Open the main menu with `/menu`.

4. Use `/rtp` to find a place to build.

5. Save your base with `/sethome <name>`.

6. Open the server shop with `/shop`.

7. Check your rewards with `/rewards`.

8. Read the gameplay changes before exploring.
