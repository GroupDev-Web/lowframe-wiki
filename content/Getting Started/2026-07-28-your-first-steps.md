# Your First Steps

This guide explains what new players should do after joining LowFrame.

## 1. Protect Your Username

Register when prompted:

`/register <password> <confirm-password>`

Example:

`/register 482917 482917`

When returning later, log in with:

`/login <password>`

## 2. Open the Main Menu

Run:

`/menu`

The main menu provides quick access to important server features.

Available options may include:

- Random teleportation

- Help

- Server information

- Shops

- Rewards

- Other LowFrame features

## 3. Find a Place to Build

Run:

`/rtp`

This teleports you to a random location.

Use random teleportation to:

- Find unused land

- Start a base

- Explore

- Move away from busy areas

Avoid building directly beside another player's base without asking.

## 4. Save Your Base

LowFrame allows you to create unlimited homes.

Set a named home:

`/sethome <name>`

Example:

`/sethome base`

Return to it with:

`/home <name>`

Example:

`/home base`

You can create as many homes as you need.

Useful home names include:

- `base`

- `mine`

- `farm`

- `shop`

- `village`

- `nether`

- `end`

## 5. Return to Spawn

Run:

`/spawn`

Spawn may contain:

- Information

- NPCs

- Menus

- Shops

- Portals

- Server selectors

- Public areas

## 6. Open the Shop

Run:

`/shop`

Select a category to buy or sell items.

To sell supported items through a menu, run:

`/sellgui`

Check your balance with:

`/balance`

## 7. Claim Rewards

Run:

`/rewards`

You may also have access to:

`/battlepass`

Rewards may include items, money, crate keys, or other bonuses.

## 8. Read the Gameplay Changes

LowFrame changes some normal Minecraft mechanics.

Most importantly:

- There is no fall damage in the Overworld.

- Newly added mobs do not naturally spawn in the Overworld.
