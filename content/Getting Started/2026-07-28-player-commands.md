# Player Commands

This page lists the commands that normal LowFrame players are most likely to use.

Some commands may be temporarily unavailable while a feature is being updated.

# Server Information

## `/menu`

Opens the main LowFrame menu.

## `/help`

Displays help information or available commands.

## `/rules`

Displays the server rules.

## `/discord`

Displays information about the LowFrame Discord server.

## `/link`

Starts the Discord account-linking process.

Follow the instructions displayed after running the command.

# Account Commands

## `/register <password> <confirm-password>`

Registers and claims your username.

Example:

`/register 482917 482917`

## `/login <password>`

Logs into a claimed username.

Example:

`/login 482917`

# Travel Commands

## `/spawn`

Teleports you to spawn.

## `/rtp`

Randomly teleports you to a new location.

## `/tpa <player>`

Requests to teleport to another player.

Example:

`/tpa ExamplePlayer`

## `/tpahere <player>`

Requests that another player teleport to you.

Example:

`/tpahere ExamplePlayer`

## `/tpaccept`

Accepts a teleport request.

## `/tpdeny`

Rejects a teleport request.

## `/back`

Returns you to your previous location when available.

# Unlimited Home Commands

LowFrame allows unlimited homes.

## `/sethome <name>`

Creates a named home.

Example:

`/sethome base`

## `/home <name>`

Teleports to a named home.

Example:

`/home base`

## `/homes`

Lists your saved homes.

## `/delhome <name>`

Deletes a saved home.

Example:

`/delhome oldbase`

# Economy Commands

## `/balance`

Shows your current balance.

Common aliases include:

`/bal`

`/money`

## `/pay <player> <amount>`

Sends money to another player.

Example:

`/pay ExamplePlayer 500`

## `/baltop`

Shows the balance leaderboard.

## `/wallet`

Displays your available currencies.

# Shop Commands

## `/shop`

Opens the main shop.

## `/shop <section>`

Opens a specific shop category.

Example:

`/shop blocks`

## `/sellgui`

Opens a menu where supported items can be sold.

## `/sellall inventory`

Sells supported items from your inventory.

## `/sellall hand`

Sells supported items matching the stack in your hand.

## `/sellall <item>`

Attempts to sell a selected item type.

Example:

`/sellall cobblestone`

# Rewards and Crates

## `/rewards`

Opens the rewards menu.

## `/battlepass`

Opens the battle-pass menu.

## `/crates preview <crate>`

Previews the possible rewards from a crate.

Example:

`/crates preview vote`

## `/crates key inspect`

Displays your virtual crate keys.

# Player Utilities

## `/echest`

Opens your Ender Chest.

## `/afk`

Marks you as away from the keyboard.

# Chat Commands

## `/msg <player> <message>`

Sends a private message.

Example:

`/msg ExamplePlayer Can you help me?`

## `/r <message>`

Replies to the most recent private message.

## `/ignore <player>`

Hides messages from a selected player.

# Command Problems

When a command does not work:

1. Check the spelling.

2. Confirm that every required value was included.

3. Check whether you are on the correct LowFrame server.

4. Try reconnecting.

5. Check the wiki page for the feature.

6. Contact staff when the problem continues.
