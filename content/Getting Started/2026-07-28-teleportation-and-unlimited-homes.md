# Teleportation and Unlimited Homes

LowFrame provides several commands for traveling and saving locations.

## Random Teleportation

Run:

`/rtp`

This sends you to a random location.

Use it when:

- Starting a new base

- Searching for unused land

- Exploring

- Moving away from crowded areas

Wait for the teleport to finish before moving or running another teleport command.

## Spawn

Run:

`/spawn`

This returns you to the main server spawn.

Spawn may contain:

- Server information

- NPCs

- Shops

- Menus

- Portals

- Server selectors

- Public areas

## Player Teleport Requests

Request to teleport to another player:

`/tpa <player>`

Example:

`/tpa ExamplePlayer`

Request that another player teleport to you:

`/tpahere <player>`

Example:

`/tpahere ExamplePlayer`

Accept a request:

`/tpaccept`

Reject a request:

`/tpdeny`

Do not repeatedly send teleport requests after a player rejects them.

## Unlimited Homes

LowFrame allows players to create unlimited homes.

Create a home with:

`/sethome <name>`

Example:

`/sethome base`

Return to the home with:

`/home <name>`

Example:

`/home base`

List all saved homes:

`/homes`

Delete a home:

`/delhome <name>`

Example:

`/delhome oldbase`

## Suggested Home Names

You can create homes such as:

- `base`

- `mine`

- `farm`

- `village`

- `shop`

- `nether`

- `end`

- `stronghold`

- `spawner`

- `friendbase`

Use clear names so your homes are easy to remember.

## Back Command

Run:

`/back`

This may return you to:

- Your previous teleport location

- Your location before using `/spawn`

- Your location before using `/home`

- Your last location before death

- Another recently saved location

The exact result depends on what you did before running the command.

## Teleport Safety

Before accepting a teleport request:

- Check who sent it.

- Store valuable items when unsure.

- Do not accept requests from players attempting to trap you.

- Report teleport traps to staff.

- Do not repeatedly teleport players without permission.
