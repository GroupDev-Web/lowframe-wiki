# Vault

Vault is a compatibility plugin that connects economy, permissions, and chat plugins with other Minecraft plugins.

Vault does not create money, ranks, permissions, or chat formatting by itself.

It provides a shared connection that other plugins can use.

# What Vault Connects

Vault may connect plugins involving:

- Economy

- Permissions

- Chat

- Ranks

- Shops

- Crates

- Jobs

- Auctions

- Land claims

- Scoreboards

- Menus

For example, EconomyShopGUI can use Vault to access the server's selected economy provider.

# Player Guide

Vault normally has no player features or commands.

Players interact with the plugins connected through Vault.

Examples include:

- `/balance`

- `/pay`

- `/shop`

- `/sellgui`

- Crate opening costs

- Paid menu actions

Those commands belong to the connected economy or shop plugins, not Vault itself.

# Server Setup

## Required Plugins

Vault needs another plugin to provide each service.

Possible providers include:

Economy:

- ExcellentEconomy

- EssentialsX Economy

- Other Vault-compatible economy plugins

Permissions:

- LuckPerms

- Other Vault-compatible permission plugins

Chat:

- A compatible chat or prefix plugin

Vault alone is not a complete economy system.

## Installation

1. Stop the server.

2. Download Vault.

3. Upload the Vault `.jar` to:

`plugins`

4. Install an economy or permissions provider.

5. Start the server.

6. Check the console.

7. Run:

`/plugins`

8. Confirm Vault and the provider appear in green.

## Checking Vault

Run:

`/vault-info`

This can show the active:

- Economy provider

- Permission provider

- Chat provider

The command may differ between Vault builds.

The server console also normally reports which providers were detected.

# Example Economy Setup

A common setup is:

- Vault

- ExcellentEconomy

- EconomyShopGUI

ExcellentEconomy provides the balances.

Vault provides the compatibility connection.

EconomyShopGUI uses that connection to charge and pay players.

# Example Permission Setup

A common permission setup is:

- Vault

- LuckPerms

- A chat or prefix plugin

LuckPerms stores groups and permissions.

Vault allows other plugins to request the player's group or prefix information.

# Troubleshooting

## No Economy Provider Was Found

Vault is installed, but no compatible economy plugin loaded.

Check that:

- An economy plugin is installed

- The economy plugin loaded successfully

- Vault support is enabled

- The server was restarted

## A Shop Does Not Detect Money

Check that:

- Vault appears in green

- The economy plugin appears in green

- The shop plugin supports Vault

- The correct currency is selected

- No duplicate Vault files are installed

## Prefixes Do Not Appear

Vault does not display prefixes by itself.

Install and configure a chat or tab-list plugin that supports Vault or LuckPerms.

## Vault Appears Red

Read the first Vault error in the startup console.

Possible causes include:

- An unsupported server version

- A damaged plugin file

- An incompatible Vault build

- Duplicate plugin files

## Updating Vault

1. Stop the server.

2. Back up plugin configurations.

3. Replace Vault with a compatible release.

4. Start the server.

5. Confirm the economy provider reconnects.

6. Test shops, balances, ranks, and chat.
